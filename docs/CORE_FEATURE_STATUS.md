# Core Feature Status

## Implemented

- Local bilingual streaming ASR integration.
- Silero VAD segmentation.
- Room/SQLite and FTS5 fact storage and retrieval.
- JSON/CSV import with evidence display.
- Meeting transcript, query and evidence archive.
- Optional local meeting audio recording.
- CAMPPlus speaker embedding integration.
- SELF/OTHER and anonymous A/B/C/D speaker labels.
- Question-to-SELF detection and question threading.
- Synthetic online QA for Compose, Sherpa and CAMPPlus.

## In progress

- Persistent pre-meeting SELF voice profile management.
- Reliable three-sample SELF enrollment.
- Named temporary participant profiles.
- ARM64 and x86_64 artifact separation gates.

## Planned

- Local vector embeddings and hybrid SQL/FTS5/vector retrieval.
- Rebuildable local approximate-nearest-neighbor index.
- Improved overlap-aware diarization.
